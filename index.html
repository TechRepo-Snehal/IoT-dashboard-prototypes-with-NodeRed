The Foundation: The TCU

Before we look at the software, we must understand the hardware that makes it possible. In every connected asset—like a modern car—there is a specialized computer called the Telematics Control Unit (TCU).

What is it?

Think of the TCU as the "Smartphone" of the vehicle. It is a powerful onboard computer designed to communicate with the outside world.

Why is it critical?

It is inside this secure box where the eUICC (Embedded SIM) is physically soldered, ensuring it can never be removed or tampered with.

Layman's View

  • Ruggedized: Built to withstand engine heat and extreme cold.

  • Connected: Contains antennas for GPS, 4G, 5G, and Bluetooth.

  • Secure: The eUICC inside acts as the "Passport" for the TCU to join networks globally.

RSP Standards Evolution

How did we get here?

In the early days of IoT, changing a network operator meant visiting a device and physically swapping a SIM card—impossible for a car or an underground meter. Manufacturers then created "Proprietary eUICC" solutions, but this led to **vendor lock-in**. To fix this, the **GSMA (Global Mobile Association)** introduced unified SGP (Subscriber Group Personalization) standards to ensure interoperability.

RSP allows us to "digitize" the identity of a SIM, letting us send a new carrier profile over-the-air (OTA) to any device, anywhere.

SGP.02 (M2M)

Push Model

The original standard for machines. It is complex because the network must initiate the change. Best suited for industrial assets with fixed power supplies.

SM-DP: The library where profiles are prepared and encrypted.
SM-SR: The active router that "pushes" the profile to the device.

SGP.32 (IoT)

Pull Model

The future of IoT. It uses a **"Consumer-like"** approach where the device itself "pulls" the profile. Much simpler for battery-powered or mass-deployment devices.

SM-DP+: A modern server that wait for the device to request a profile.
eIM: The massive manager for your whole fleet of devices.

Mobile Core Network

The software intelligence that governs authentication and traffic security.

Why the Core Matters

The Mobile Core Network is the heart of global connectivity. It doesn't just pass data; it acts as a gatekeeper that ensures only authorized devices connect. It translates radio signals from cell towers into secure sessions.

A robust core architecture allows traffic to reach its destination in a safe and secure manner through encrypted tunnels.

End-to-End Lifecycle

A connected car journey.

1. Silicon Manufacturing

The eUICC is manufactured with a Bootstrap Profile and soldered into the TCU.

1

The Telematics Control Unit (TCU) is installed in the vehicle. It contains Layer 1 (eUICC Hardware) with a temporary factory profile.

The car wakes up. It connects to the Mobile Core via the bootstrap profile to verify hardware and download a destination-specific profile.

2

2. Initial Boot & Test

Using RSP Infrastructure, the car receives its first "Operational Profile" based on where it will be sold.

3. Global Transit

The car is shipped to another country. It enters "Shipping Mode" to save battery but stays reachable.

3

The Cloud Platform detects the car's location change via core network signaling and prepares a local profile swap if needed.

The car is sold. High-speed data is activated via the Mobile Core PGW, allowing the driver to browse and use maps securely.

4. Live Operation

The "End-to-End" stack ensures the driver has high-speed, secure internet for the life of the vehicle.
